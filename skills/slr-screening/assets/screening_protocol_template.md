## 4. Decision rules

- **TAK:** any `no` → EXCLUDE; all `yes` → INCLUDE; otherwise → MAYBE. INCLUDE + MAYBE go to full text.
- **Full text:** all `yes` → INCLUDE; any `no` → EXCLUDE (one primary reason); key criterion unresolved → UNCLEAR (contact authors).
- Low-confidence exclusions are always checked by a human.
