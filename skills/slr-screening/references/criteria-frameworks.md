# Frameworks and writing criteria you can check

## Choosing a framework

| Framework   | Use when                                                           | Elements                                                          |
| ----------- | ------------------------------------------------------------------ | ----------------------------------------------------------------- |
| **PICO(S)** | Effectiveness of interventions (clinical, educational, managerial) | Population, Intervention, Comparison, Outcome, (Study design)     |
| **PEO**     | Associations, risk factors, determinants, correlational studies    | Population, Exposure, Outcome                                     |
| **SPIDER**  | Qualitative / mixed-methods evidence                               | Sample, Phenomenon of Interest, Design, Evaluation, Research type |
| **PCC**     | Scoping reviews (JBI)                                              | Population, Concept, Context                                      |
| **CIMO**    | Management / organisational studies                                | Context, Intervention, Mechanism, Outcome                         |

For social-science, business, or information-systems reviews that test theory (e.g. TAM, UTAUT, TPB), PEO or CIMO usually fits better than PICO. Add criteria for the **theory/construct** and the **empirical method** if the review needs them.

## Always add these "technical" criteria

- **Study design**, e.g. empirical quantitative studies only, or RCTs only, or any primary empirical study.
- **Publication type**, e.g. peer-reviewed journal articles; conference papers yes/no; theses, book chapters, and editorials no.
- **Language**, e.g. English or Vietnamese.
- **Date range**, e.g. 2010–2025, with a reason (a technology launch, a policy change).
- **Availability of results**, e.g. the paper reports results (not a protocol only).

## Rules for criteria you can check

1. **One idea per criterion.** "Adults using mobile banking in Vietnam" is three criteria: population, concept, context.
2. **Say what counts as a yes.** Define key terms and list synonyms. For example, _"Mobile banking" = financial transactions via a smartphone app or mobile web; excludes ATM, internet banking on desktop, and mobile payment wallets unless linked to a bank account._
3. **Say how to handle partial fits.** Mixed samples, multi-country studies, or several outcomes of which only one is relevant.
4. **Make it decidable from the paper.** "High-quality studies" is not a screening criterion. That belongs in quality appraisal.
5. **Write inclusion and exclusion as mirror images** with the same ID, so every exclusion maps to one criterion.

## Worked example (PEO, business/IS topic)

Research question: _Which factors influence the intention of Vietnamese consumers to use mobile banking?_

| ID  | Inclusion (yes)                                                                                       | Exclusion (no)                                             | Notes for borderline cases                                                             |
| --- | ----------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| C1  | Population: individual consumers/customers (≥ 18 y)                                                   | Firms, bank employees, SMEs as units                       | Student samples are eligible                                                           |
| C2  | Exposure: antecedent factors (e.g. perceived usefulness, trust, risk) examined as predictors          | Only descriptive usage statistics, no predictors           | Qualitative factor identification is eligible                                          |
| C3  | Outcome: intention to use / adoption / continuance of **mobile banking**                              | Other fintech (e-wallets, crypto) or internet banking only | If e-wallet and m-banking are combined, include only if m-banking results are separate |
| C4  | Context: Vietnam (whole or part of sample)                                                            | No Vietnamese data                                         | Multi-country: include if Vietnam results are reported separately                      |
| C5  | Design: primary empirical study (survey, experiment, interviews)                                      | Reviews, conceptual papers, editorials                     | Keep reviews on a separate list for citation chasing                                   |
| C6  | Publication: peer-reviewed journal article or full conference paper; English or Vietnamese; 2010–2025 | Theses, book chapters, abstracts only, other languages     |                                                                                        |

## Worked example (PICO, health)

Question: _In adults with type 2 diabetes (P), do smartphone self-management apps (I), compared with usual care (C), improve HbA1c (O) in RCTs (S)?_

- C1 Adults ≥ 18 y with T2DM. (Mixed T1/T2 samples: include if T2 results are reported separately or T2 ≥ 80%.)
- C2 The intervention is a smartphone app for self-management. (SMS-only or web-only: exclude.)
- C3 The comparator is usual care or no app.
- C4 HbA1c is reported as an outcome. (At TAK stage, glycaemic control not named explicitly → `unclear`, not `no`.)
- C5 RCT, including cluster and crossover designs.
- C6 Peer-reviewed; any language with an English abstract; 2008 onwards.

Note on C4: **outcomes are often not in the abstract.** At TAK, an outcome that is not mentioned is usually `unclear`, not `no`, unless the abstract clearly lists only other outcomes.
