# Borderline record types – default handling

The defaults below apply unless the protocol says otherwise. Whenever you apply one, note it in `notes` so the researcher can override it.

| Situation                                                              | TAK stage                                                                                                                                                                                  | Full-text stage                                                                                                                                     |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **No abstract**                                                        | Screen on the title and keywords. If the title is relevant or ambiguous → `MAYBE`. Exclude only if the title alone is clearly out of scope.                                                | Normal.                                                                                                                                             |
| **Non-English / non-eligible language**                                | If language is a criterion and it is clear from the record → `EXCLUDE` `LANGUAGE`. If there is only an English abstract of a foreign-language paper, check whether the protocol allows it. | Same. Do not machine-translate to "rescue" a paper unless the protocol allows translation.                                                          |
| **Conference abstract only**                                           | Usually `EXCLUDE` `PUB_TYPE` if the protocol requires full papers. Otherwise `MAYBE`, and search for a full paper.                                                                         | If a full paper by the same authors exists, link it as the same study and screen the full paper.                                                    |
| **Study protocol / trial registration**                                | `EXCLUDE` `PUB_TYPE` (no results). Note it: a results paper may exist.                                                                                                                     | Same, `NO_DATA`.                                                                                                                                    |
| **Systematic / narrative reviews**                                     | `EXCLUDE` `DESIGN` if only primary studies are eligible, **but** tag `notes = "citation-chasing"` so the reference list can be searched.                                                   | Same.                                                                                                                                               |
| **Preprint and published version**                                     | Keep both at TAK if not caught as duplicates.                                                                                                                                              | Link them as one study. Use the peer-reviewed version as the primary report. The other becomes `DUPLICATE`, or a linked report.                     |
| **Retracted paper**                                                    | Flag it if the record says so.                                                                                                                                                             | `EXCLUDE` `RETRACTED`. Tell the user.                                                                                                               |
| **Mixed population** (e.g. adults + adolescents)                       | `MAYBE` unless clearly mostly out of scope.                                                                                                                                                | Apply the protocol's threshold (e.g. ≥ 80% eligible, or subgroup reported separately). If none is set, ask the user and add a rule to the protocol. |
| **Multi-country study including the target country**                   | `MAYBE`.                                                                                                                                                                                   | Include only if results for the target context are separable, unless the protocol accepts pooled results.                                           |
| **Same dataset, several papers**                                       | Screen each normally.                                                                                                                                                                      | Include all eligible reports, but link them to one study ID in `linked_reports`, so the synthesis does not double-count samples.                    |
| **Grey literature** (reports, working papers)                          | Follow the protocol's `PUB_TYPE` rule.                                                                                                                                                     | Same.                                                                                                                                               |
| **Title/abstract contradicts the full text**                           | –                                                                                                                                                                                          | Go with the full text. Note the contradiction.                                                                                                      |
| **Wrong or garbled metadata** (title from another paper, empty fields) | Flag it as `REVIEW`. Do not guess.                                                                                                                                                         | Check against the PDF.                                                                                                                              |

## Signs of drift (check after every batch)

- Similar records getting different decisions, e.g. two PLS-SEM surveys of students where one was included and the other excluded.
- Reason codes changing for the same kind of problem.
- The share of `MAYBE` falling sharply over time. This often means the reviewer is growing more lenient about excluding when unsure.

If you see drift, re-screen the affected records against the written criteria. Do not change the criteria quietly.
